{% translate "Privacy" %}

{% translate "This page describes what personal data this site stores, where, for how long, and how you can have it deleted. Magic Personality is a small, non-commercial project for a closed circle of about 3 to 10 people (see About) — there is no advertising, no analytics, and data is never shared with third parties." %}

{% translate "What is stored" %}

  • {% translate "Account: your email address and a hashed password (Argon2) — the password itself is never stored." %}
  • {% translate "Profile: your nickname, an optional short bio, and the colors you have chosen or taken over from a test. Your profile picture is generated from these colors on the fly — it is never uploaded or stored as a file." %}
  • {% translate "Test history: each time you take the personality test, the date, your points per color, and the resulting combination are stored privately in your own history." %}
  • {% translate "Security logs: to prevent abuse, the IP address of every attempt to enter the invite code, register, or log in is recorded, together with the attempted email address for login attempts." %}
  • {% translate "Session: while you're logged in, a session identifier is stored in a cookie in your browser and matched against a record on the server, so you stay logged in between visits." %}
  • {% translate "Access cookie: this whole site sits behind an invite code. Once entered, a signed cookie remembers that on your device — it contains no personal data, only a signed \"granted\" marker." %}

{% translate "Where" %}

{% translate "This site runs on a single small server hosted at STRATO (a data center within the EU; the exact location isn't visible to us). Nightly backups of the database are kept in the same hosting environment for 14 days, then deleted automatically (see below)." %}

{% translate "How long" %}

  • {% translate "Account, profile, and test history: for as long as your account exists." %}
  • {% translate "Security logs (IP addresses of invite-code, registration, and login attempts): currently kept indefinitely — there is no automatic cleanup yet. Removable manually on request (see below)." %}
  • {% translate "Backups: 14 days on a rolling basis, then deleted automatically." %}
